# Icon

`peek.svg` is the PeekBuddy logo of nobuddy.org (`web-buddy/public/logos/peek.svg`
in the site repository). `peekbuddy.ico` (16, 24, 32, 48, 64 and 256 px, PNG
frames) is the icon of `peekbuddy.exe`; `window-64.rgba` is the 64 px raw RGBA
image of the viewer window and taskbar icon. Both are rendered from the SVG;
render them again when the logo changes.
